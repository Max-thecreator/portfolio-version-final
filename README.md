## Technique

Site statique, sans dépendance ni framework. Hébergé par GitHub Pages.

- HTML sémantique, thème sombre, responsive (mobile, tablette, ordinateur)
- Accessibilité : lien d'évitement, repères ARIA, focus visible, `prefers-reduced-motion`
- Référencement : balises Open Graph et Twitter Card pour l'aperçu des liens partagés
- Feuille de style d'impression
